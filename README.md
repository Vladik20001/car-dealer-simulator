# Car Dealer Simulator

Car Dealer Simulator is an open-source Unity simulation game focused on realistic vehicle trading and business management.

Players buy, sell, upgrade, and manage vehicles while balancing prices, inventory, customer demand, and long-term progression. The goal is to create a playable simulator with clear economy systems, data-driven gameplay, and maintainable architecture.

## Project Goals

- Build a realistic car trading and dealership management simulator
- Create reusable systems for economy, inventory, pricing, upgrades, and progression
- Keep the codebase beginner-friendly and easy to understand
- Document the development process for other indie developers
- Make the project open-source so others can learn from it or contribute

## Planned Features

- Vehicle buying and selling
- Dynamic pricing and profit calculation
- Car upgrades and repairs
- Dealership inventory management
- Customer demand simulation
- Progression and business growth systems
- Save/load system
- Clean Unity project structure

## Why This Project Is Open Source

This project is intended to be more than just a game. It is also a learning resource for developers interested in simulation games, economy balancing, and Unity architecture.

By keeping the project open-source, other developers can study how the systems are designed, adapt ideas for their own projects, and contribute improvements over time.

## Status

The project is currently in early development.
